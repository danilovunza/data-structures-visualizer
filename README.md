# Data Structures Visualizer

## Overview

The Data Structures Visualizer demonstrates the behavior of fundamental data structures used in computer science.

The project implements:

* Stack
* Queue
* Linked List
* Binary Tree
* Hash Table

---

## Data Structures

### Stack

Last In, First Out (LIFO)

### Queue

First In, First Out (FIFO)

### Linked List

Dynamic node-based structure.

### Binary Tree

Hierarchical tree structure.

### Hash Table

Key-value storage system.
